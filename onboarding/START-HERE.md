# Set up Relay

Relay is installed, and the Relay app has already connected the person's account on this computer. Nothing needs installing, signing in or approving here, and you run no setup commands.

Call Relay's `relay_onboarding_current` tool (without MCP: `relay onboarding current`, or the managed skill's helper with `call relay_onboarding_current`), then follow the First Relay tutorial in the installed Relay skill. If it reports no active setup, help the person with Relay as usual.
